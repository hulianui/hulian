# CRM 后台 Demo（slice 2-6 + Kanban 组件）实现计划

> **For agentic workers:** 用 superpowers:executing-plans 逐任务实现，checkbox 跟踪。

**Goal:** 把 CRM demo 的 6 个占位/桩页面替换为真实全交互的 `@hulian/ui` 页面，并新增可复用的 `Kanban` 组件。

**Architecture:** 每页本地 `useState` 从 mock 种子化（刷新还原）；100% 用 `@hulian/ui`，撞缺口就扩库。Kanban 是库级新增（dnd-kit 多容器），先 TDD 再被看板页消费。

**Tech Stack:** Next.js App Router（client components）、`@hulian/ui`、`@dnd-kit/core`+`@dnd-kit/sortable`、vitest + RTL。

## Task 1: Kanban 组件（TDD）

**Files:**
- Create: `packages/ui/src/kanban/kanban.types.ts`、`kanban.tsx`、`index.ts`、`kanban.showcase.tsx`、`kanban.test.tsx`
- Modify: `packages/ui/src/index.ts`、`packages/ui/src/showcase.ts`、`apps/www/lib/manifest.ts`

参考：先读 `packages/ui/src/sortable/sortable.tsx` + `sortable.test.tsx` 学既有 dnd-kit 用法/测试风格/无障碍水准；读一个既有 showcase（如 `sortable.showcase.tsx`）学 `ShowcaseSpec` 形状；读 `manifest.ts` 学条目结构。

**API**（见 spec §4）：`KanbanColumn{id,title,header?,footer?}`、`KanbanProps<T>{columns,items,getId,getColumnId,onMove,renderItem,renderColumnHeader?,className?,columnClassName?}`，`onMove({id,fromColumn,toColumn,toIndex})`。

- [ ] **Step 1: 写 types** — 按 spec §4 落 `kanban.types.ts`。
- [ ] **Step 2: 写失败测试** `kanban.test.tsx`：
  - 渲染：给 3 列 + 跨列分布的 items，断言每列渲染了正确卡片（按 `getColumnId` 分桶）。
  - 列头统计：`renderColumnHeader` 收到该列 items，自定义头出现。
  - 空列：无 item 的列仍渲染为合法容器（droppable 占位文案/空区可见）。
  - 键盘移动：聚焦卡片→空格抓起→方向键→空格落下，触发 `onMove`（参照 sortable.test 的 KeyboardSensor 断言方式；若 dnd-kit 键盘测试在 jsdom 不稳，则降级为单测 `onDragEnd` 解析逻辑：抽出纯函数 `resolveMove(activeId, overId, columns, items, getId, getColumnId)` 直接单测）。
- [ ] **Step 3: 跑测试确认失败** — `pnpm --filter @hulian/ui test kanban` → FAIL。
- [ ] **Step 4: 实现 `kanban.tsx`** — DndContext（Pointer+Keyboard sensors）；按 `getColumnId` 分桶；每列 droppable + SortableContext（vertical）；卡片 useSortable；DragOverlay 渲染浮层；`onDragEnd` 解析目标列/index 调 `onMove`。把解析逻辑抽 `resolveMove` 纯函数便于测试。
- [ ] **Step 5: 跑测试确认通过** — `pnpm --filter @hulian/ui test kanban` → PASS。
- [ ] **Step 6: 写 showcase + 注册** — `kanban.showcase.tsx`（一个小看板示例）；`index.ts` 加 `export * from "./kanban"`；`showcase.ts` 注册；`manifest.ts` 加条目（category=`data-display`，tags 含 Kanban/拖拽）。
- [ ] **Step 7: 提交** — `git add packages/ui/src/kanban packages/ui/src/index.ts packages/ui/src/showcase.ts apps/www/lib/manifest.ts && git commit -m "feat(ui): 新增 Kanban 看板组件(dnd-kit 多容器跨列拖拽)"`
